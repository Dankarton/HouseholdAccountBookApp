# 家計簿アプリ

このアプリは，日々の収支を記録しながら，購入日と支払日が異なる支払方法 (例:クレジットカード，後払いサービス)にも対応できる家計簿アプリです．
従来の家計簿では購入日ベースでしか残高を管理できないことが多いですが，本アプリでは実際の引き落とし日を反映することで，正確な時系列の残高を
確認できます．これにより，将来の支払予定を含めた実際の資金状況を把握でき，安心して家計管理を行うことが出来ます．   
本アプリでは，金銭のやり取りに関係なく購入した日や契約した日を支出日，実際に支払いが行われた日を支払日として扱っています．  

## 主な機能
- **収支の記録**  
  日々の収入・支出をカテゴリー別に登録可能です．支払方法を選択することで，支出日と支払日が自動的に入力されます．  
- **月次データの一覧表示**  
  1か月ごとのデータを日付順に表示します．残高に加えて翌月以降の支払金額も確認可能です．  
- **円グラフ**  
  支出・収入のカテゴリ別割合を円グラフで表示します．  
- **データの編集・削除**  
  一覧表示画面から支出データの編集・削除が可能です．  
- **カテゴリ・支払方法の管理**    
  設定画面で支出・収入カテゴリや支払方法の追加・編集・削除が可能です．  
- **初期残高の設定**    
  初期残高を設定することで，正確な残高計算を行えるようになります．
## 画面説明
**1. 入力画面**    
「支出」「収入」「振替」の3つの入力タイプがあり，日々の資産変動を正確に記録できます．<br>
- *支出入力*  
  支出額，メモ，支出カテゴリに加えて支払方法を選ぶことで，対応するウォレットや，引き落とし日などの情報を基に自動的に支払の記録が付きます．<br>
- *収入入力*  
  収入額，メモ，収入カテゴリに加えて振り込み先のウォレットを選ぶことで，資産残高との紐づけが行えます．<br>
- *振替入力*  
  「銀行口座から現金を下ろした」「電子マネーにチャージした」など，ウォレット間での資金の移動を記録できます．<br><br>
![img](https://github.com/user-attachments/assets/3126cb84-40da-4744-8144-796f558eef76)<br><br>
**2. カレンダーデータ表示画面**  
収支とウォレットの残高確認を月次ベースで可視化できます．<br>
- *収支の確認*
  月間の収支がひと目でわかるように，各日付にドットが表示されます．プラス収支は青，マイナス収支は赤に色分けされます．さらに，収支額の大きさに応じてドットのサイズが動的に変化するため，大きなお金の動きがあった日を直感的に特定できます．<br>
- *ウォレットの確認*
  その日の最終的なウォレットごとの残高をリストで確認できます．<br><br>
以下の画像は，5月の収支とウォレット画面の画像です．一日ごとのオブジェクトはそれぞれプルダウンリストを持っており，詳細なデータを確認したい日付をタップすることで，リストが展開されます．収支画面では，その日の支出，収入を主データとして確認することができ，ウォレット画面では実際のお金の動きを確認できます．<br>
本アプリでは使用したクレジットカードの仕様(月末締め・翌月27日引き落とし)を登録できます．そのためクレジットカードで支払った交際費分の支出は，5月1日当日の時点では実際の資金変動は発生していないと判定され，5月1日のウォレット残高には反映されていません．実際の資産変動は，設定されている翌月27日の引き落とし日(6月27日)に反映されています．<br><br>
![img](https://github.com/user-attachments/assets/7dc008a1-a846-4734-9b3a-e08251ea1af5)<br><br>
**3. チャート画面**<br>
記録したデータを自動で集計し，カテゴリ別の割合を円グラフで可視化することで，収支の傾向を視覚的に分析するための画面です．<br><br>
